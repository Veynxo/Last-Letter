**Traps**
> 

> Traps are very simple, For example let’s do the trap “SD” the way to give it is by knowing a word that ends with it, For example “Esd” it’s a working word in last letter that ends with sd and it will give your opponent “SD” there is many solves for it but a trap works by having a giver and few solves. A normal word like Hello gives lo (In casual) But lo has a-lot of words starting with it, That’s why it isn’t a trap, But traps like “NZ” Giver = sbrinz have only very few solves which are considered traps.
> 

<u>*The difference between Casual and Pro traps.*</u>

> Casual traps only work by having 3 solve groups, For example “Koy” it’s now a casual traps “Why?” Because koy has more than 3 groups 3 groups meaning 3 or more solves that have no relation to each other so for example, Realization and realizations are the same group because its the same word but with an abbreviation or Plural or past or present or future participle, That’s how it works if it’s less than 3 groups then it’s considered a pro trap because it only works in pro servers.
> 

***Pro traps***

> Pro traps have 1 or more groups, For example “onic” it only has 1 group which is onicolo it only has 1 solve so it won’t work in casual because 1 or more groups meaning its a pro trap it’s pretty simple to understand, It’s only for competitive players:
